## Definition of done for every task / 每个任务的完成标准

- [ ] Acceptance criteria are met and linked to evidence / 验收标准已满足并链接证据
- [ ] Relevant automated or manual tests are recorded / 已记录相关自动或手动测试
- [ ] Failure behavior is tested / 已测试失败行为
- [ ] Secrets and personal data are absent / 不包含密钥与个人数据
- [ ] Sources, assumptions, and freshness are visible where relevant / 相关位置展示来源、假设与时效
- [ ] Documentation reflects the new behavior / 文档与新行为一致
- [ ] The learner can explain the design and trade-offs / 学习者能解释设计与取舍
- [ ] A short learning note is included in the PR / PR 中包含简短学习记录
