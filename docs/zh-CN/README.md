# TripPilot 中文学习入口

欢迎来到 TripPilot。这个仓库的目标不是尽快“做出一个聊天框”，而是通过一个可验证的旅行策划场景，逐步理解 LLM 应用的关键构件。

## 推荐阅读顺序

1. [项目说明](../project-brief.md)：明确用户、范围与非目标。
2. [架构说明](../architecture.md)：理解组件边界与一次请求的完整数据流。
3. [学习路线](../learning-roadmap.md)：按阶段学习 LLM、RAG、工具、Agent、MCP、Skill 和评测。
4. [任务清单](../task-list.md)：把阶段目标拆成可以验收的小任务。
5. [ADR 指南](../decisions/README.md)：记录关键选择及取舍。

## 教学模式

你负责写全部应用代码。向 AI 求助时，优先让它：解释概念、提出苏格拉底式问题、评审你的方案、设计测试或指出风险。除非你明确改变规则，否则不要让 AI 直接完成某个里程碑的实现。

每个阶段结束时，请用自己的话回答三个问题：

1. 数据从哪里来，经过了哪些步骤？
2. 哪些结果是确定事实，哪些是模型推断？
3. 系统失败时，用户能否理解并安全恢复？
